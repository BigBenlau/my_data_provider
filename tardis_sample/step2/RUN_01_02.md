## 使用 03 對帳

從 Git 專案根目錄進入 `tardis_sample/step2`。將 `RUN_ID`、`EXCHANGE` 設為 02 的批次及交易所，將 `START_UTC`、`END_UTC` 設為雙方資料重疊的時間窗（含時區的 ISO 時間或 epoch 微秒）。

```bash
python3 03_compare/03_compare_tardis.py \
  --ours "02_normalize_tardis/output/$RUN_ID/$EXCHANGE" --tardis ../datasets \
  --start "$START_UTC" --end "$END_UTC" --output "03_compare/output/$RUN_ID/$EXCHANGE"
```

在輸出目錄查看 `comparison.json`。舊版的 `output/03_comparison/` 對應目前的 `03_compare/output/`。[對帳程式](03_compare/03_compare_tardis.py)
